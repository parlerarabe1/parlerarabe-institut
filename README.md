# Parler Arabe Institut — site

Site statique prêt pour GitHub Pages.

## Mise en ligne
1. Créer un dépôt GitHub (par exemple `parlerarabe-institut`).
2. Déposer tous les fichiers et le dossier `assets`.
3. Dans Settings → Pages, choisir le déploiement depuis la branche principale (`main`) et le dossier `/ (root)`.
4. Le fichier `index.html` sera la page d'accueil.

Le domaine personnalisé `parlerarabe.fr` pourra être connecté ensuite dans GitHub Pages.
